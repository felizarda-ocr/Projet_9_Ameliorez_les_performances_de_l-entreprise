Résumé du projet
---
Conception d'un tableau de bord Power BI pour Bottleneck, société de vente de vin en ligne, permettant de visualiser et piloter les performances commerciales grâce à une analyse centralisée des données de vente, de stock et de clientèle.

Tâches réalisées
---
**Analyse des besoins :** Identification des KPI stratégiques (ventes, stocks, comportement client) avec l'équipe dirigeante.

**Intégration des données :** Connexion sécurisée via ODBC, puis nettoyage et transformation des données avec Power Query (processus ETL).

**Développement du tableau de bord :** Création de visualisations interactives sur les ventes par gamme, la gestion des stocks et l'analyse client.

**Recommandations stratégiques :** Rédaction d'un rapport de synthèse avec préconisations pour optimiser les performances.

Compétences mobilisées
---
**Outils BI :** Power BI (visualisation, DAX), Power Query (ETL)

**Data Analysis :** Analyse de données business, définition de KPI

**Connexion données :** ODBC, SQLite

**Orientation métier :** Visualisation orientée décisionnelle, reporting stratégique
